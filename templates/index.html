⚠ Setup Required
Marginalia needs at least one API key to run cloud models. Local models (DeepSeek, Gemma, Llama) work without keys — but you need Ollama running and models downloaded first.
Step 1
Open setup.env in your marginalia folder
In Terminal:
open -e ~/Developer/marginalia/setup.env
Step 2
Paste your API keys — get them free at:
GOOGLE_API_KEYaistudio.google.com → Get API Key (free)
ANTHROPIC_API_KEYconsole.anthropic.com → API Keys (pay-as-you-go)
OPENAI_API_KEYplatform.openai.com/api-keys (pay-as-you-go)
Step 3
Save setup.env and restart Marginalia
Ctrl+C in the terminal, then double-click bootstrap.command again.
Optional — Local models
For DeepSeek R1, Gemma 4, and Llama 3.1
Requires Ollama installed and models pulled:
ollama pull deepseek-r1:8b
ollama pull gemma4
ollama pull llama3.1:8b

If models are on an external drive, set OLLAMA_MODELS_PATH in setup.env.
Already set your keys? Restart Marginalia — this screen won't appear again.

Typed PDFs extract instantly. Scanned or handwritten PDFs are flagged for Gemma OCR.

Typed PDFs extract in seconds. Handwritten PDFs are processed page by page via Gemma 4 OCR (~15–45s per page).
